# Leszno Tire Lab

Portfolio project by RENFI DIGITAL — a premium, futuristic automotive performance & tire workshop website.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes
- The contact form in `components/Contact.tsx` posts to a placeholder Formspree endpoint
  (`FORMSPREE_ENDPOINT` constant). Replace it with your own Formspree form URL, or swap in
  another form backend, before going live.
- Photography is sourced from Unsplash via remote URLs for the demo; replace with licensed
  brand photography for production use.
- All tire specs, pricing-free product info and business data are placeholder/demo content.
